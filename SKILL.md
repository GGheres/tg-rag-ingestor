# SKILL.md

## REAL INTEGRATION SKILL

### Purpose

Этот skill описывает обязательный способ реализации внешних интеграций, backend-сервисов, jobs, CLI-утилит и API-клиентов.

---

## RULES

### 1. No fake runtime behavior
Не симулируй успех, если реальный вызов не выполнялся.

### 2. Fail fast on missing config
Если не хватает env/config/secrets, приложение или модуль должно завершаться с понятной ошибкой.

### 3. Real contracts only
Работай только от реальной документации, реальных endpoint-ов, реальных payload-схем и реальных ограничений.

### 4. Honest delivery
Явно разделяй:
- что реализовано
- что реально проверено
- что не может быть проверено без доступов

### 5. Mandatory logs
Все ключевые шаги, внешние вызовы и ошибки должны логироваться подробно и безопасно.

### 6. Mandatory comments
Сложная логика, интеграции, ограничения и архитектурные решения должны быть объяснены комментариями в коде.

### 7. No hidden fallback
Нельзя тихо переключаться на sample data, local JSON, fake adapter или sandbox path без явного разрешения пользователя.

---

## REQUIRED IMPLEMENTATION PATTERN

Для любой внешней интеграции:

1. Проверить обязательную конфигурацию
2. Если конфигурации нет, сразу сообщить о блокере
3. Реализовать клиент под реальный API
4. Добавить timeout, обработку ошибок, retries при необходимости
5. Добавить подробное логирование
6. Добавить комментарии на сложные и критичные места
7. Явно указать, была ли выполнена реальная end-to-end проверка

---

## DELIVERY FORMAT

При сдаче задачи всегда указывать:

- что сделано
- какие env нужны
- какие доступы нужны
- что проверено реально
- что не проверено
- какие блокеры остались
